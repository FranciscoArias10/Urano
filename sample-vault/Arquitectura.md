# 🏛️ Arquitectura de Urano

Urano fue diseñado desde cero para máxima eficiencia y bajo consumo de recursos:

- **Desktop Core:** Tauri 2.0 (Rust)
- **Frontend:** React + TypeScript + Tailwind CSS
- **Motor de Edición:** CodeMirror 6 con extensiones modulares para Markdown y Wikilinks
- **Grafo:** HTML5 Canvas de alto rendimiento con `force-graph`
- **Base de Datos de Sincronización:** SQLite embebido en `.urano/sync.db`
